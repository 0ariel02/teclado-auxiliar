# teclado-auxiliar
práctica atajos de teclado
1. Teclado Virtual Táctil: Evita que el teclado nativo del teléfono intercepte atajos (como   Ctrl+S   que guarda la página). Los botones tienen un tamaño mínimo de 48x48px para cumplir con las pautas de accesibilidad táctil.
2.
Sistema de Modificadores: Toca   Ctrl   o   Shift   (se iluminarán en azul) y luego toca la letra para simular combinaciones reales.
3.
Retroalimentación Háptica: Usa   navigator.vibrate   para dar una pequeña vibración al acertar o fallar, mejorando la sensación de "teclado físico".
4.
Diseño Responsive: Usa Tailwind CSS con un diseño "Dark Mode" idéntico al de GitHub, optimizado para pantallas verticales.
5.
Categorías: Puedes filtrar para practicar solo "Repositorio", "Código" o "Issues", haciendo las sesiones de práctica más cortas y efectivas.
